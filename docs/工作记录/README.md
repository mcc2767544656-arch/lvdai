# 工作记录

按日期归档的开发/联调记录。每份记录包含：当天做了什么、为什么这么做、验证数据、遗留问题。

写这些文档的目的不是汇报，而是**下次接手时能快速恢复上下文**——尤其是那些「踩过一次就不想再踩」的坑（端口、频率单位、串口冻结、双重混控之类）。

## 约定

- 目录名用 `YYYY-MM-DD`
- 主文档固定叫 `工作记录.md`
- 原始数据放 `data/`，并在 `data/README.md` 里写清字段和质量问题
- 用到的临时脚本放 `tools/`，保证别人能复现
- 只写**可验证的事实**：数字带单位和测量条件，结论标注置信度；推测明确标成推测
